HtmlDiv Inline / Baseline 示例（HTML/CSS 近似对照）

说明： - 子元素 display=inline 会在父容器内按行内流排版并自动换行 - 行内元素按 baseline 对齐（这里用 inline-block baseline 近似） - margin-top/bottom 对 inline-block 的行盒高度影响与 Flutter 实现可能不同

基线对齐：不同高度的 inline 盒子底边对齐

换行：宽度不足时自动折行

text-indent：只影响第一行（支持 px/%）

inline + FitContent：受可用宽度影响（内部可换行）

inline 嵌套与 inline 中嵌套 block

inline + margin-top/bottom（影响行盒高度）
