HtmlDiv Margin 示例（HTML/CSS 近似对照）

相邻垂直边距折叠：max / min / sum

A: height 40, margin-bottom 20
B: height 40, margin-top 10

负边距：不同符号时相加

A: height 40, margin-bottom -10
B: height 40, margin-top 20

负 margin-top：产生重叠（向上拉动）

A: height 40, margin-bottom 0
B: height 40, margin-top -10 (overlap)

水平边距：影响可用宽度与 x 偏移

left 24 / right 48
left 48 / right 24

百分比边距：相对包含块宽度解析

left:10% right:0
left:0 right:10%

margin auto：水平剩余空间分配（居中/靠左/靠右）

left:auto right:auto (center)
left:20 right:auto (left=20)
left:auto right:20 (shift right)
